# Question rules

## Tiers

Tier each topic from the assessed sources, strongest evidence first. Record the evidence in the registry entry.

| Tier | Evidence | Questions |
| --- | --- | --- |
| T1 assessed | Tested by a graded assignment, its rubric, or a past exam | Copy a registered question type and its rubric criteria, at exam difficulty. Most questions go here. |
| T2 practised | Appears only in exercise sets or practice problems | Exercise-style questions, fewer than T1. |
| T3 slides only | No assessed or practice source found so far | No quiz questions; at most one recognition check. The notes mark the topic "not assessed so far". Never drop it silently. |

Re-tier when new material appears (unlocked exams, new assignments, published solutions). A topic only moves up a tier from new evidence, never because it seems important.

## Pretest

- 2–3 single-select questions with 4 options through the question tool, plus 1 short written question.
- Neutral options with no hints; randomize the position of the correct option; never mark an option as recommended.
- Draw from registry types that fit the topic. For procedural types (closures, decompositions, queries, proofs) the written question is the one that counts.
- A topic the learner fully gets right is confirmed in one line and not taught again.

## Quiz round

- 3–6 questions after teaching. Ask the learner to answer before any solution appears.
- Every question must be answerable from what was taught and the source slides already covered. Do not test later topics.
- Mix types: recall, explain in your own words, compare, apply to a small instance, and the topic's registered assessed types.
- When a rubric exists, grade against its criteria and name the criterion each mark comes from.

## Answer key

1. **Official first.** Use the official solution when one exists (exercise-set solutions, past-exam solutions, a closed assignment's published solutions). Label it with its source and a link.
2. **Otherwise the model solves first.** Before asking, the model works the question itself and writes that key to the question bank. It grades the learner against it and labels it **model answer, not official**.
3. If the learner's answer exposes an error in a model key, say so, fix the key in the bank, and grade fairly.

## Graded assignments

- Open: use only the assignment's format, scope and rubric to write look-alike questions on different instances. Never work on, hint at, or check the actual graded questions.
- Closed: its questions may be used as practice, graded under the answer-key rules above.

## Misses

Log a miss when an answer is partly correct or needs work. A miss is resolved after correct answers in two separate sessions; rephrase it in a new context each time rather than repeating the question.
